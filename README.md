## 📝 Descripción del Proyecto
El objetivo principal de este trabajo práctico es introducir y aplicar los fundamentos de **JavaScript** en conjunto con el trabajo colaborativo.

A lo largo de los ejercicios, se resuelven distintos problemas lógicos y algorítmicos orientados a afianzar las bases de la programación estructurada.

## 📂 Estructura del Repositorio
El repositorio cuenta con una carpeta principal denominada `src/` donde se encuentran los distintas carpetas (`html`, `js`, `css`,`services` etc.) con la resolución individual de cada consigna planteada en el Trabajo Práctico.
